\section*{41}
Suppose we had a function $f$ with an initial value of $x_0$, and such that the functions first three iterates are $x_1=2,x_2=2$ and $x_3=8$. 
Now, $x_1=f(x_0)$, $x_2=f(x_1)$, and $x_3=f(x_2)$. Thus we would have $2=x_2=f(x_1)=f(2)$ and $8=x_3=f(x_2)=f(2)$. Thus we would have $f(2)=8$ and $f(2)=2$, a
contradiction. This means that this situation cannot occur.

\section*{42}
(a): We are given a recursive sequence defined by $a_1=3,a_2=10$ and $a_n=4+2a_{n-1}-a_{n-2}$. The first five terms of the sequence are
$3,10,4+2(10)-3=21,4+2(21)-10=36,4+2(36)-21=55$.


(b): Note that the differences are in the following sequence: $10-3=7,21-10=11,36-21=15,$ and $55-36=19$. Each term increases by a common difference of 4, meaning this is arithmetic. 
The sequence of the differences can therefore be expressed by $d_n=7+4(n-1)$.


(c): We have a sequence representing the differences in each successive term. What this means is that the $n$th term in the recursive series is equal to $3$ plus 
the sum of the differences up to that 
point, that is (because this is an arithmetic series): $s_n=n\frac{d_1+d_n}{2}=n\frac{7+7+4(n-1)}{2}=n\frac{14+4(n-1)}{2}=n(7+2(n-1))$. 
Thus an explicit rule for the sequence is $a_n=3+s_{n-1}=3+(n-1)(7+2(n-2))$.

\section*{47}
(a): A rule to model the amount of the drug in the bloodstream after $n$ doses is: $a_n=a_{n-1}\times 0.7+20$.


(b): Note that, by similar reasoning as in Problem 62 of 7.3, the $n$th term of this sequence is equal to 
the sum of the first $n$ terms of the geometric series with $a_1=20$ and $r=0.7$, that is: \[ 20\dfrac{1-0.7^n}{1-0.7} \]
We are asked to find the maitenence level of the bloodstream. There are three ways we can do this. The first is by simply finding the limit of the above sum 
(that is, what value $a_n$ approaches), which is:
\[ \lim_{n\rightarrow\infty}\left(20\dfrac{1-0.7^n}{1-0.7}\right) \]
\[ =20\times\lim_{n\rightarrow\infty}\dfrac{1-0.7^n}{1-0.7} \]
\[ =20\times\dfrac{\lim_{n\rightarrow\infty}(1-0.7^n)}{0.3} \]
\[ 20\times\frac{1}{0.3}=\frac{20}{0.3}=\frac{200}{3} \]
Alternatively, we could find the limit by finding the infinite sum of the above geometric series (as the infinite sum is just what value the partial sums approach, that 
is, what value $a_n$ approaches), which is:
\[ \frac{20}{1-0.7}=\frac{20}{0.3}=\frac{200}{3} \]
Another way to solve this is by assuming we had found some maintenance level $a_m$ at all. What this would mean is that $a_{m+1}=a_m$, that is, 
\[ a_m=a_m\times 0.7+20 \] \[ a_m\times 0.3=20 \] \[ a_m=\frac{20}{0.3}=\frac{200}{3} \]
(Here was the solution I initially had. I tried to find the limit of the below expression. Plugging this into an online limit calculator, the correct limit of 
$\frac{200}{3}$ is obtained, so this seems to be a correct alternative solution. However, I must be misunderstanding limits, as to me it seems that the limit should be 20. 
This is because $\lim_{n\rightarrow\infty}(0.7)^{n-1}=0$, which would then multiply by zero. Does this not work, as the product limit rule does not work if 
one of the limits is $0$? And how would one go about solving the below limit correctly?)\newline
This is the answer to the above question: The limit product rule does not apply there, because \[ \lim_{n\rightarrow\infty}(1-(\frac{10}{7})^{n-1})=-\infty \] The limit 
product rule only works for finite limits.


Yet another possible way of solving this problem is using the first sum discussed in Problem 63 of 7.3. In this case, it would be:
\[ 20\left(\dfrac{1-(\frac{1}{0.7})^{n-1}}{1-\frac{1}{0.7}}\right)(0.7)^{n-1}+20 \]
\[ =20\left(\dfrac{1-(\frac{10}{7})^{n-1}}{1-\frac{10}{7}}\right)(0.7)^{n-1}+20 \]
\[ =-\frac{140}{3}\left(1-(\frac{10}{7})^{n-1}\right)(0.7)^{n-1}+20 \]
To find the maitenance level, we find the limit of the above expression:
\[ \lim_{n\rightarrow\infty}\left(-\frac{140}{3}\left(1-(\frac{10}{7})^{n-1}\right)(0.7)^{n-1}+20\right) \]
\[ =20-\frac{140}{3}\lim_{n\rightarrow\infty}\left(1-(\frac{10}{7})^{n-1}\right)(0.7)^{n-1} \]
\[ =20-\frac{140}{3}\lim_{n\rightarrow\infty}\left((0.7)^{n-1}-1\right) \]
\[ =20-\frac{140}{3}(0-1) \]
\[ =20+\frac{140}{3}=\frac{200}{3} \]


(c): If the dosage level $d$ doubles, then, if we had a maintenance level $a_m$ at all:
